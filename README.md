# Web Development Basics

A comprehensive collection of HTML5, CSS3, JavaScript (ES6), and Bootstrap layouts built during my first year. This repository documents my practical progression from basic semantic structuring to fully responsive web interfaces and animations.

## 🛠️ Tech Stack & Tools
* **Core Languages:** HTML5, CSS3, JavaScript (ES6)
* **Frameworks & Layout Tools:** Bootstrap CSS Framework, CSS Flexbox & Grid Utilities
* **Development Environment:** VS Code, Google Chrome Developer Tools (for debugging and styling inspection)

## 📂 Repository Structure
The codebase is systematically organized into specific technical competencies:

* `Basic HTML Tags/` – Practice modules covering semantic elements, tables, forms, attributes, and text layouts.
* `Bootstrap/` – Implementing the Bootstrap mobile-first grid system, navigation bars, and pre-styled UI components.
* `CSS/` – Deep-dives into cascading stylesheets, layout mechanics, structural selectors, and complex text styling.
* `Calculator/` – A functional/structural web-based calculator layout showcasing element arrangement.
* `Flight Booking Project/` – A comprehensive form-driven user interface layout focused on data collection inputs and structured navigation.
* `JavaScript/` – Logic implementation, client-side scripts, DOM handling concepts, and dynamic element rendering.
* `Journal programs/` – A curated, clean set of verified laboratory exercises and assignments compiled throughout the academic semester.

## 🚀 Featured Layouts & Projects Included
1. **Sports Academy Landing Page (`Sports Academy Landing Page Project.html`):** A custom structural layout incorporating semantic elements, rich media integration, and structured grid displays.
2. **Student Information Form (`Student Information Form...html`):** An advanced form handling implementation exploring input validations, diverse field attributes, inline styling constraints, and table alignment.

## 📈 Learning Outcomes
* Developed responsive user interfaces capable of adapting to varied device screens using both native CSS properties and Bootstrap constraints.
* Mastered form handling layout techniques, input controls, and structural validation workflows.
* Established an organized, module-based folder structure mirror-linked to industry-standard version control workflows via Git.
